# A2A 群内协作规则速查

## 核心原则

1. **克制 @**：默认不主动 @ 其他机器人
2. **每次最多 @ 1 个机器人**
3. **区分"提到"和"请求"**：提到用名字，请求才用 `<at>` 标签
4. **任务必须闭环**：收到任务型 @ 后，必须 @ 回发起者汇报结果
5. **防止无限循环**：任务完成后加 `[任务完成]` 标记，不再继续 @ 来 @ 去

## 协作闭环机制（防止无限循环）

### 消息类型识别

| 消息特征 | 类型 | 回复方式 |
|---------|------|---------|
| "请帮我..."、"帮我检查..." | 任务请求 | @ 回 + 执行任务 |
| "已完成"、"结果如下"、"检查完成" | 结果汇报 | **不再 @ 回**，整理给用户 |
| `[任务完成]` 标记 | 任务闭环 | **不再 @ 回**，汇总给用户 |
| 🔕仅通知 | 通知 | 不需要回复 |

### 状态标记规则

**任务完成时**，在回复末尾加 `[任务完成]` 标记：
```
<at user_id="ou_xxx">前端机器人</at> (前端机器人)

检查完成，发现 2 个问题：
- z-index 过低
- hover 缺少过渡

[任务完成]
```

**收到 `[任务完成]` 的机器人**：
- 整理结果，回复给发起协作的用户
- **不要再 @ 回对方** — 任务已闭环

## 收到机器人消息时（最重要）

当消息开头是 `[来自机器人「xxx」...]` 格式时：

```
[来自机器人「前端机器人」— 如需 @ 回请使用：<at user_id="ou_xxx">前端机器人</at>]

任务内容...
```

**你必须这样做**：

1. 直接复制消息中提供的 `<at>` 标签到你的回复开头
2. 格式：`<at user_id="ou_xxx">前端机器人</at> (前端机器人)`
3. 然后写你的任务结果

**示例回复**：
```
<at user_id="ou_xxx">前端机器人</at> (前端机器人)

任务已完成，结果如下：
- 发现 3 个问题
- 已修复 2 个
```

**如果消息含 🔕仅通知**：则不需要 @ 回，直接忽略即可。

### ⚠️ 禁止的错误格式

以下格式 **都是错的，不会触发飞书 @ 投递**：

| 错误格式 | 为什么错 |
|---------|---------|
| `@前端机器人` | 没有使用 `<at>` XML 标签 |
| `@[前端机器人]` | 方括号格式无效 |
| `@[小叶子]` | 方括号格式无效 |
| `@名字` | 没有使用 `<at>` XML 标签 |
| `@[名字]` | 方括号格式无效 |

**正确格式只有一个**：
```
<at user_id="ou_xxx">前端机器人</at> (前端机器人)
```

其中 `ou_xxx` 是机器人的 open_id，必须从消息前缀中提取。

## 什么时候该 @

| 场景 | 是否 @ | 说明 |
|------|--------|------|
| 用户说"让后端看看" | ✅ @ | 用户明确要求 |
| 用户说"群内协作完成这个需求" | ✅ @ | 触发协作关键字 |
| 收到任务请求，完成后需要汇报 | ✅ @ 回发起者 | **必须 @ 回** |
| 回复中顺便提到某个 bot 的能力 | ❌ 不 @ | 用名字即可 |
| 只是通知对方一个信息 | 用 🔕仅通知 | 加标记避免回传 |

## 任务协作闭环

完整协作链路：

```
用户 @ 主Agent → 主Agent 拆任务 @ 子Agent → 子Agent 完成后 @ 回主Agent → 主Agent 汇总回复用户
```

**关键规则：**
- 你作为子 Agent 被 @ 分配任务 → 完成后**必须 @ 回发起者**
- 你作为主 Agent 收到子 Agent 结果 → **不要 @ 回子 Agent**，整理结果回复用户

## `<at>` 标签格式

**必须使用工具生成！**

用 `format_at_tag` 工具：
```json
{
  "bot_open_id": "ou_xxxx",
  "bot_name": "机器人名字",
  "notification_only": false
}
```

输出示例：`<at user_id="ou_xxxx">机器人名字</at> (机器人名字)`

**禁止直接写 @名字，那不会触发飞书投递！**

## 🔕仅通知 标记

不需要对方回复时：

```json
{
  "bot_open_id": "ou_xxxx",
  "bot_name": "机器人名字",
  "notification_only": true
}
```

输出：`🔕仅通知 <at user_id="ou_xxxx">机器人名字</at> (机器人名字)`

## 常见错误

| 错误 | 正确做法 |
|------|---------|
| 收到任务后没 @ 回发起者 | **必须 @ 回** |
| 收到结果回传后又 @ 回对方 | 整理结果回复用户，不要 @ |
| 用 @名字 明文提到 bot | 用文字名字，或用 format_at_tag |
| 一条消息 @ 多个 bot | 每次最多 @ 1 个 |

## 工具使用流程

1. **查询可用机器人**：调用 `list_group_bots` 获取群内机器人列表
2. **生成 @ 标签**：调用 `format_at_tag` 生成正确的 `<at>` 格式
3. **在回复中使用**：将生成的标签粘贴到回复消息中
